# KAN-16 Testni BIN zapis

Ta mapa vsebuje testni BIN zapis, ki je bil uporabljen kot dokaz, da zajem podatkov iz DataLogger naprave deluje pravilno.

Datoteka je namenjena preverjanju:
- ali se podatki pravilno shranijo,
- ali je BIN zapis berljiv,
- ali lahko kasneje uporabimo parser za nadaljnjo obdelavo signalov.

Ta mapa še ne predstavlja končne učne množice, ampak samo začetni testni primer zajema podatkov.
